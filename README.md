基于 STM32 与 FreeRTOS 的智能家居系统
硬件平台： STM32F103, ESP8266, DHT11 项目描述： 设计并实现了一套包含“端-边-云-管”的完整物联网系统。基于 FreeRTOS 构建实时多任务架构，通过 MQTT 协议实现设备与云端的高效交互，并开发配套 Android App 实现远程监控。 主要工作与难点：
•	RTOS 架构设计： 移植 FreeRTOS 实时操作系统，将数据采集、网络通信、逻辑控制划分为独立任务 (Task)，利用二值信号量和消息队列解决高并发下的资源竞争与同步问题。
•	物联网通信协议： 封装 AT 指令集驱动 ESP8266，实现基于 MQTT 的设备上云；设计心跳包 与断网重连机制，解决了复杂网络环境下的连接稳定性问题。
全链路系统开发： 独立完成从原理图绘制、底层驱动编写到上位机 App 开发的全栈工作。
